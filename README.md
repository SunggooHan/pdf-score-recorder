# PDF Score Recorder MVP

PDF 악보를 보면서 카메라/마이크로 연주 영상을 녹화하는 웹앱 MVP입니다.

## 기능

- PDF 파일 선택 후 브라우저에서 렌더링
- 페이지 이동
- 확대/축소/화면폭 맞춤
- 자동 스크롤
- 카메라/마이크 켜기
- 녹화 시작/정지
- 녹화본 미리보기 및 다운로드
- 연주 모드: 상단 메뉴를 숨기고 악보를 크게 표시, 하단 미니 컨트롤 제공

## 실행 방법

카메라/마이크 접근은 보안 정책상 `file://`로 연 HTML에서는 잘 동작하지 않습니다. 로컬 서버나 HTTPS에서 실행해야 합니다.

### 가장 쉬운 실행법

1. 이 폴더를 압축 해제합니다.
2. 터미널에서 폴더로 이동합니다.
3. 아래 명령을 실행합니다.

```bash
python3 -m http.server 8000
```

4. 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8000
```

## iPhone/iPad에서 테스트하는 방법

가장 간단한 방법은 Mac에서 위 서버를 실행하고, iPhone/iPad가 같은 Wi-Fi에 있을 때 Mac의 로컬 IP로 접속하는 것입니다.

예시:

```text
http://192.168.0.10:8000
```

단, 일부 iOS 환경에서는 카메라/마이크가 HTTPS가 아닐 때 제한될 수 있습니다. 이 경우 GitHub Pages, Netlify, Vercel 같은 HTTPS 환경에 올려 테스트하세요.

## 연주 모드 사용법

1. PDF를 불러옵니다.
2. 필요하면 카메라를 켭니다.
3. 상단의 `연주 모드` 버튼을 누릅니다.
4. 연주 모드에서는 하단 미니 컨트롤로 페이지 이동, 자동 스크롤 속도 조절, 녹화 시작/정지를 할 수 있습니다.
5. `나가기`를 누르면 일반 모드로 돌아갑니다.

키보드나 블루투스 페이지터너가 방향키/스페이스 입력을 보내는 경우, 연주 모드에서 다음 조작을 사용할 수 있습니다.

- `←`: 이전 페이지
- `→` 또는 `Space`: 다음 페이지
- `Esc`: 연주 모드 나가기

## 주의사항

- iOS Safari는 녹화 포맷 지원이 Chrome과 다를 수 있습니다. 앱은 `mp4`를 먼저 시도하고, 지원되지 않으면 `webm`으로 녹화합니다.
- 장시간 녹화는 브라우저/기기 메모리 영향을 받습니다. MVP 검증 단계에서는 1~3분 단위로 먼저 테스트하는 것을 권장합니다.
- 현재 버전은 녹화 중 PDF 화면을 영상에 합성하지 않습니다. 카메라로 보이는 연주 영상만 저장합니다.
